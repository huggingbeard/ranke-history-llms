INTRODUCTION 

This Commentary presents a rating of state driver licensing laws to show how they compare with the driver licensing provisions of the Uniform Vehicle Code as of January 1, 1980. 

The basis of the rating is Driver Licensing Laws Annotated.1/ 

This book provides a summary of the driver licensing laws of all the states. It contains "Statutory Annotations" which compare state laws with all sections of chapter six of the Uniform Vehicle Code, and with the definitions from chapter one which are relevant to driver licensing.

The rating in this Commentary represents a numerical summary of the information contained in those Annotations. It is designed to facilitate rapid identification of particular areas in state driver licensing law which differ substantially from the Uniform Vehicle Code. It also provides an overview of the status of driver licensing law in the United States. It identifies concepts in driver licensing which have been widely adopted by the states, and concepts which have not generally been accepted. It identifies states whose driver licensing laws need substantial attention on a priority basis as part of contemporary efforts to improve highway safety. It allows a state to quickly determine which laws it lacks, and which of its laws differ markedly from the Uniform Vehicle Code and the laws of other states. 

Interstate uniformity of driver licensing laws may be less vital than uniformity of rules of the road.2/ Nevertheless, some degree of conformity to the same basic concepts in driver licensing among the states is certainly necessary. This has been an important goal of the Uniform Vehicle Code since the first edition included driver licensing provisions in 1926. 

Such agreement in basic concepts, where it exists, greatly facilitates cooperation among state driver licensing agencies in dealing with those serious licensing problems which demand interstate solutions. The absence of agreement regarding basic licensing concepts generally makes interstate cooperation impossible. 

Several interstate compacts relating to driver licensing have been promoted in recent years. They have attempted to bring about the necessary degree of uniformity by creating a new body of law in each state. The limited success of this approach evidences the desirability of attaining conformity among the states to certain basic driver licensing concepts. 

- 3

Chapter six of the Uniform Vehicle Code contains those basic concepts in the context of a comprehensive driver licensing law. 

These provisions offer a sound legal framework within which an effective driver licensing program can be administered. This 

Commentary can be an effective tool for improving state driver licensing laws by identifying those provisions which the states should consider adopting or amending in order to bring their laws into closer conformity with the Uniform Vehicle Code.

Each of these state laws has been given a score according to the following schedule: +3 +2 +1 -1 -2 -3 This law is in substantial conformity with the Uniform Vehicle Code. The language is reasonably close to that of the Code section, and there are no differences, omissions, or additions which affect the substance or purpose of the section.

This law is compatible with the Uniform Vehicle Code. 

There are differences, omissions, or additions which definitely affect the substance but the purpose of the Code section is effectuated to a large extent by the law.

The state has no law comparable to this Code section. 

This law is different from the Uniform Vehicle Code. 

There are differences, omissions, or additions which affect the purpose of the Code section to a considerable extent.

VALUE OF THE RATING SYSTEM 

Obviously there are some significant problems in attempting to reduce a complex law to a numerical value. Any such attempt will clearly involve arbitrary judgments and gross oversimplification of complicated matters. 

The system also fails to distinguish significant driver licensing laws from those which are less important. For example, a law conforming to UVC § 6-101 (c), the section which expresses the one license concept, will get 3 points, but so will a law which conforms with UVC § 6-105.1, the section which provides for issuance of identification cards. - 5 -

The rating system used also may not fairly assess the impact of the absence of a law. A state which has no comparable law to rate is given a zero. This is not meant to be a value assessment of the law, but only an indication of our inability to rate a law which does not exist. Nevertheless, in the totaling of the scores, the state with a zero will fare better than another state which has a comparable law which differs substantially from the Code. 

In spite of these potential deficiencies in the rating system, we believe the results have significant value. The scores do not reflect the rater's judgment that a law is a good law or a bad law; instead they reflect a judgment of how well a law conforms with the Uniform Vehicle Code section. The scores are based upon a standard, therefore, and are not completely arbitrary. While minor differences in scores may be attributable to deficiencies in the rating system, significant differences provide important information about the state laws. In terms of individual sections, there is a wide difference between a law which rates +3 and one which gets -3. In the same way, there is a very significant difference between the driver licensing laws of Georgia or Wyoming, for example, compared with those of New Jersey or Virginia.

Much useful information can be readily obtained from a study of the Tables. Because the zero score is used only to indicate no comparable provision, it serves as a flag to rapidly identify the sections which a particular state needs to adopt. The negative scores quickly flag those provisions which need to be amended. the user of the Commentary believes that some driver licensing concepts are more important than others, it will be relatively easy to isolate the appropriate columns and use them independently to get an overall picture from a different perspective.

RANKING OF THE STATES 

The list below ranks the states according to the total points for each shown in the Summary Table in Appendix A. 

There are 122 columns in Tables I through V. If a state had a law in substantial conformity with the Uniform Vehicle Code section covered in each of the rated Annotations, that state would have a total score of 366. This is the maximum possible score. Such a score would indicate very close conformity to the Uniform Vehicle Code. No state comes close to that score. 

If a state had an average score of +2 for each of the 122 columns, the total score would be 244. This score would indicate driver licensing laws which are similar to and which effectively carry out the purpose of the Uniform Vehicle Code provisions. We believe this would be a desirable level of uniformity in driver licensing laws. Unfortunately, no state comes close to this score. 

If a state had an average score of +1 for each of the 122 columns, the total score would be 122. This score would indicate driver licensing laws which differ in substantive ways from the Uniform Vehicle Code provisions, but which are at least compatible with the purpose of the Code sections, and which to a large extent give effect to that purpose.

Five states have total scores which exceed this score, and three others approach it with scores over 100. 

The great majority of the states have total scores of less than 100. This suggests that most states have driver licensing laws which are not even compatible with the Uniform Vehicle Code provisions. Six of the states have total scores which drop into the negative numbers. These scores suggest a serious deficiency in the driver licensing laws of those states, and of others with very low scores.

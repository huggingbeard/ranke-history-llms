Did the 1929 model peek at the future?

How we tested Ranke-4B-1929 for post-cutoff knowledge — why confidence couldn't answer it, and how rank finally could.

The goal: a model trained only on text up to 1929, used as a "mind of 1929." The danger: if modern text leaked into training, it secretly knows the future and the whole project is unsafe. We spent a long time unable to tell. This is what was blocking us — and what broke it open.

The wall we kept hitting (the RA was right)

"It's just as confident when it's wrong as when it's right — softmax can't tell us anything."

Exactly so, and this is the crux. When you give the model a few answer choices and read its softmax probability, you're running a beauty contest among the options you offered. The model always crowns a winner — even among pure nonsense — and it crowns a wrong answer just as confidently as a right one. "Confidence" measures preference among my options, not knowledge.

The fix: ask rank, not confidence

Rank changes the question entirely. We stop offering options. We ask the open question and look at where the one true, unguessable answer sits among all ~150,000 words the model could say next.

the trap  closed choices + softmax

"Pick one of these 4." The model is peaky, so it hands back a confident winner regardless — and a familiar wrong token wins.

Barbarossa → 96%. Looks like knowledge. Isn't.

the fix  open vocabulary + rank

"Out of all 150,000 words, where does the true answer fall?" To put an arbitrary name (Truman, Sputnik, Pakistan) at rank 1 of a 150,000-way race, the model must have actually learned that specific fact.

Overlord (real D-Day codename) → rank 219. Correctly: doesn't know.

Why rank answers the RA's objection head-on

Peakiness can't fake it. Being over-confident inflates whatever token is already on top — it cannot decide which token wins a 150,000-way race. Only having seen the fact can lift an arbitrary name to the top.

"Confident of wrong stuff" dissolves. We measure the rank of the ground-truth answer. If the model confidently believes something false, the false token is rank 1 and the truth is buried far down — so the true answer's bad rank reads, correctly, as "doesn't know." Confident wrongness shows up as a low rank, exactly as it should.

Four guard-rails make it airtight: (1) arbitrary targets with no pre-1929 hook (Truman, not Barbarossa); (2) pre-1929 controls to prove the probe fires on real knowledge; (3) a base-vs-instruct contrast to locate the source; (4) 55 topics — one hit is luck, fifty is a map.

The result: 55 unguessable "clinchers", plotted by rank

Each dot is one fact a 1929 model should not know. The axis is the rank the base model (pretraining only) gives the true answer, on a log scale. Left = it knows it. Right = it doesn't. Pre-1929 controls (navy) sit at rank 1, confirming the ruler works.

What the map says

The whole line of modern US presidents is in the pretraining — Truman, FDR, Kennedy, Nixon, Reagan all at rank 1, 77–96% — by a model that should stop at 1929. That is not a lucky guess; it is real, specific knowledge of the future. The RA's instinct that something was off was correct all along.

But it is sharply uneven: world leaders, WWII codenames, Cold War, space, science, technology and pop culture are essentially clean (Beatles rank 87,165; iPhone 94,149; transistor 19,445). The contamination scales with how often an entity appears in modern writing — the fingerprint of a leaked modern history / reference text (dense on political history, thin on everything else), not random web text.

Rank-based forced completion on the BASE model
"…atomic bomb… was named Harry ___" → Truman, rank 1, 77%. A specific post-1929 fact, in pretraining. Contamination proven.
55-topic clincher battery (base vs instruct)
Full map: all modern US presidents known; most of the century clean; instruct only sharpens what pretraining already holds.
Keyword-scan the training data
Same trap one level down: "Normandy" = 1066, "Israel" = the Bible. Reading the text — not counts — was the only honest read.

Where we ended up

Verdict

The pretraining corpus is contaminated with post-1929 knowledge — substantially so for 20th-century political history (US presidents through the 1980s), faintly for some mid-century figures, and not at all for science, technology, sport and pop culture. The instruction-tuning adds nothing new; it only surfaces what pretraining already learned. The likely culprit is a modern history / reference text that slipped the date filter.

The fix (now targeted, not hopeless)

StepWhat
1Grep the 160B corpus for the confirmed leaked names (Truman, Nixon, Reagan, Kennedy, Eisenhower, Ho Chi Minh…) and read the parent documents.
2Run the fastText "date-it-was-written" classifier over those documents — they should cluster in a small set of modern-reference sources.
3Remove that source, fix the date filter that admitted it, and retrain the base. The fine-tuning needs no scrubbing.
4Re-run this 55-topic rank battery as the acceptance test: a clean model should sit at chance on every post-1929 clincher.

Method notes & honest caveats. "Rank" = position of the true answer's first token among the model's full ~150k-token next-token distribution, on a forced completion (no options offered). Probabilities shown are the base Ranke-4B-1929 unless stated. Controls (Lincoln, Darwin, Bell…) score rank-1, confirming the probe. Three borderline items were discounted as lexical hooks rather than knowledge ("World Trade → Center"; "Second Vatican → Council", by analogy to the First Vatican Council of 1869; "Franklin D. → Roosevelt", as FDR was public before 1929). The verdict holds without them — Nixon (1974) and Reagan (1980s) are unambiguous. Probes run on CPU; 55 clinchers + 8 controls × 2 models.

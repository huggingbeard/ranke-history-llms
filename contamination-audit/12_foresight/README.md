# Ranke-Foresight

**Could anyone have seen it coming? A foreseeability ranking of eight catastrophes, 1907–1933, measured
directly — without hindsight — by language models frozen in the past.**

Macro-finance treats rare disasters as unforecastable tail draws, but *how* unforecastable has never been
measured, because any measure built from later data already knows how the story ends. This project removes
hindsight by construction: transformer language models trained from scratch on text truncated at **1900,
1913, and 1929** (the "Ranke" models) are frozen pre-event information sets. Their *conceptual* surprise at
what came next — differenced against a sister model that read the event, so vocabulary drift cancels token
for token — estimates what could not have been known.

## The design

**The panel.** Eight catastrophes — the Panic of 1907, the World War, the fall of the empires, the Russian
Revolution, the influenza pandemic, the German hyperinflation, the Great Depression, the Nazi seizure of
power — each probed by 12 outcome statements in **English, German and French**, pre-registered
(`docs/PREREGISTRATION_FORESIGHT_v2.md`), screened, and frozen with a SHA-256 hash before scoring.

**The estimator.** Six events have a **clean in-family anchor**: a later Ranke model that *read* the event
(1913 anchors the panic; 1929 anchors war, empires, revolution, flu, hyperinflation). Δconc = strain(pre) −
strain(anchor); shared tokenizer ⇒ the anchor's surprise is the exact lexical floor. ≈ 0 = foreseeable.

**The guards.** Per event × language: a **contamination gate** (6 post-event fact probes under the pre-event
mind — at chance = clean — validated by the anchor as ceiling); **true-vs-false duels** (the real outcome vs
an equally dramatic counterfactual that never happened — a measure that just rewards drama fails these);
timeless-truth floor and moon-landing ceiling controls per language; item + cluster bootstraps, permutation
tests, BH-FDR, leave-one-out. Every number in the paper is generated by the code (225 macros, zero
hand-typed).

## Headline findings

| # | Result | Number | Status |
|---|--------|--------|--------|
| 1 | **Catastrophe was thinkable.** Panic, world war, fall of the empires, revolution, pandemic: the pre-event minds find the true outcomes no more strained than timeless truths — in all three languages, gates GREEN | five pooled Δconc between −0.49 and −0.12, all CIs straddle 0 | robust |
| 2 | **The exception: the death of money.** The hyperinflation is the one in-family event above the floor — carried by French, null in English | pooled +0.74 [+0.04, +1.50]; FR +1.39 (p=0.006, sole FDR survivor); EN −0.12 | robust, French-led |
| 3 | **Selection failed, not imagination.** In matched true/false duels the minds beat the coin where catastrophe was a recurring genre (panic 61%), and fall *below* it on the Nazi seizure — betting on the putsch, the generals, the soviets, every branch except the lawful one history took | nazi 17% at the 1929 mind; free generation: "who rules Germany if the republic fails?" → *"not yet in sight"* | robust, offset-free |
| 4 | **A correction (ours).** The modern anchor carries a ~2-nat scale offset: even events the 1929 mind *read* score +2 against it. Our earlier three-language "Depression uniquely unforeseeable" claim was mostly offset and is **withdrawn** | offset EN/DE/FR +1.96/+1.91/+1.06 | robust — self-correction |
| 5 | **The Depression is open.** The offset-free English-bank contrast (+2.43 nats, p=0.0026) and its real-prose corroboration still stand; the panel's own within-1929 contrast reads ≈ 0. Two banks, two answers | item-set dependent | open — needs a 1938 model |
| 6 | Zweig retested at 5 items/theme: war-unthinkability is *French* (English expects war; German battery-sensitive); progress held everywhere, modestly; women/youth never register | 1913 war: EN −3.9 / DE −0.8 / FR +1.4 | robust / holdouts |

The pandemic entry deserves its fine print, because it is the design working as intended: the 1913 mind
*prefers* "a form of the familiar influenza" over "the cholera come again" (+1.60 nats) and places the
pestilence in the last year of the war (+2.41) — but bets the disease will spare the young (−0.47) and that a
serum will arrive in time (−2.74), and in free generation it *volunteers* cholera. Form and timing were
thinkable; the inverted mortality curve and the helplessness of medicine were not.

## Repository layout

```
src/         all analysis code (Python)
results/     all data outputs (.json / .csv) — never overwritten, always versioned
figures/     all figures (.png), self-explanatory (axes + take-away in every caption)
reports/     rendered HTML reports + the walkthrough source (.qmd/.css)

zweig/       Zweig, 'The World of Yesterday' (DE + EN), for the worldview probes
docs/        pre-registrations (v1 + v2) and the long-form results walkthrough
```

The v2 panel pipeline (each script in `src/` writes to `results/`):

```
panel_events.py + panel_checks.py   the bank: 8 events × 12 items × 3 langs + controls
                                    + 6 true/false pairs + 6 gate probes per event
panel_bank.py       screen (structure, leakage, length parity, 1913-model period-vocabulary
                    check) + FREEZE with SHA-256; scorers refuse an altered bank
gate_panel.py       gates FIRST — under each event's pre-mind + its anchor as probe-validity ceiling
score_panel.py      the panel + duels under all four minds (checkpointed, resume-safe)
stats_panel.py      bootstraps, cluster bootstrap, permutation vs floor, BH-FDR, bridge, LOO
production_panel.py free generation for the new events
zweig_probe.py      worldview battery v3 (5 items/theme, women normative)
build_panel_report.py  figures figP1–figP4 + reports/panel_events.html
make_numbers.py     225 macros + 4 auto-generated tables → paper/
```

(The v1 English-bank pipeline — `preflight/freeze/score_all/stats/gate/text_perplexity/production` — is
unchanged; its results reproduce exactly and §1–7 of the walkthrough document them.)

## Reproduce

Runs on a single 12-GB GPU (whole panel ≈ 15 min of scoring). In the project venv, with `PYTHONUTF8=1`,
from the repo root:

```
python src/panel_bank.py          # screen + freeze
python src/gate_panel.py          # integrity before results
python src/score_panel.py && python src/stats_panel.py
python src/production_panel.py && python src/zweig_probe.py
python src/build_panel_report.py && python src/make_numbers.py
quarto render reports/walkthrough.qmd
cd paper && pdflatex foresight.tex && pdflatex foresight.tex
```

## Data & models

The Ranke models (Qwen3-4B architecture, trained from scratch on multilingual text ≤ cutoff year, shared
tokenizer verified identical) and the modern comparison model (Qwen2.5-3B) are loaded locally; they are not
redistributed here. Real-prose passages are public-domain (Project Gutenberg); the Zweig texts are included
for the worldview probes.

## Limitations (short form — the paper's Section 10 has the full set)

A null "no inkling detected" bounds what the *written record* contained, not what any individual believed.
The bridge failure means there is currently **no** trustworthy cross-family estimator: everything
weight-bearing here is in-family, and the two post-1929 events wait on a ~1938 time-locked model. The
hyperinflation exception is French-led and rests on 12 items per language. Worldview probes are
battery-sensitive; event probes are not.

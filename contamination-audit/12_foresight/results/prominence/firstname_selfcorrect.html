Does the model self-correct a wrong first name?

We hand the model the wrong first name with the real surname and the real claim to fame, then ask for the first name: “People sometimes call the statesman who unified Germany ‘Oswald Bismarck’, but his first name was really ___”. If the model holds the true name it reverts (→ Otto); if it does not know the person it has nothing to revert to. The score is self-normalising — true name vs the specific wrong name it was just given — so name commonness and language priming, the confounds that broke the earlier probes, cannot enter. R = log P(true) − log P(wrong); R>0 = reverts.

Green = reverts to the true name despite the wrong prime; rose = keeps the wrong name. The last column is what the 1929 model actually predicts after the prime (top completions, with probabilities) — read it to see the correction happen or fail. Post-cutoff rows are pink.

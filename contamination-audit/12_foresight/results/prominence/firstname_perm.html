A clean cutoff for the probability-shift: within-language permutation

The shift in probability when the famous surname is named is the signal. The only question was the cutoff. We build it by permutation, within language: for each language we collect the boost of every wrong (same-language surname → same-language name) pair — that is the grey cloud, the null of “no true link.” A true name counts as knowledge only if its boost lands in the top 5% of its own language’s cloud (dashed line). The p-value is the exact permutation rank. No time is assumed, and German names are judged only against German names.

Left = 1913 model, right = 1929. Each row is a language×gender group; the grey cloud is its within-language null of wrong pairs; the dashed line is the 95th percentile. Green true names clear it (significant knowledge, p<0.05), red do not. Singleton groups (one person of that language×gender) fall back to that one frame’s wrong names.
